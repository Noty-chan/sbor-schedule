# Сбор

Адаптивный прототип двухнедельного расписания для театральной труппы.

## Что работает

- регистрация и сохранение входа в браузере;
- быстрая циклическая отметка доступности на 14 дней;
- статусы «свободен», «с ограничениями» и «не могу»;
- временной интервал для ограниченной доступности;
- создание администратором отдельных временных слотов;
- ответы участников по каждому слоту;
- автоматический рейтинг пересечений и сводка ответов;
- список спектаклей и предупреждения о конфликтах;
- фильтрация участников по постановкам;
- демонстрационный режим администратора;
- мобильная версия.

## Firebase

Приложение использует Firebase Authentication и Cloud Firestore проекта `abricos`.

Облачная синхронизация настроена для профилей, доступности, слотов, ответов, пресетов и спектаклей. Консоль Firebase должна сохранять следующие настройки:

1. Включить вход по Email/Password в Firebase Authentication.
2. Создать базу Cloud Firestore.
3. Добавить `noty-chan.github.io` в Authorized domains.
4. Опубликовать правила из `firestore.rules`.
5. UID Даши закреплён администратором в правилах и автоматически получает `role: admin` в профиле.

Если Firestore временно недоступен, приложение автоматически использует локальное хранилище: Firebase Authentication продолжает работать, но расписание не синхронизируется между устройствами. При первом успешном облачном входе администратора локально созданные слоты и доступность переносятся в Firestore один раз. Публичная конфигурация веб-приложения находится в `firebase-config.js`. Секретные ключи и Service Account в репозитории не хранятся.

## Готовые рабочие функции

- регистрация, вход и восстановление пароля;
- календарь доступности на 14 дней с быстрым переключением статусов;
- слоты с точным временем и индивидуальными ответами;
- рейтинг пересечений только среди участников нужного спектакля;
- создание и редактирование спектаклей;
- создание, редактирование и удаление слотов;
- назначение участников в составы;
- отключение доступа к приложению администратором.
- фильтр «Мои слоты» и индикатор неотвеченных слотов;
- подсказка, если ответ на слот конфликтует с отметкой дня.
- мобильный конструктор недели для администратора;
- пресеты с названием, длительностью, местом и участниками;
- добавление блока одним тапом с автоматическим переводом времени;
- использованные на неделе пресеты остаются доступными внизу списка;
- администратор вместо личной доступности сразу видит сетку и ответы участников.

Будущий сервер в Нидерландах сможет взять на себя настоящее отключение Firebase Auth-аккаунтов через Firebase Admin SDK. Основная синхронизация расписания уже работает через Firestore.
