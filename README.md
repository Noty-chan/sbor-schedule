# Сбор

Адаптивный прототип двухнедельного расписания для театральной труппы.

## Что работает

- регистрация и сохранение входа в браузере;
- быстрая циклическая отметка доступности на 14 дней;
- статусы «свободен», «с ограничениями» и «не могу»;
- временной интервал для ограниченной доступности;
- создание администратором отдельных временных слотов;
- ответы участников по каждому слоту;
- автоматический рейтинг пересечений и сводка ответов;
- список спектаклей и предупреждения о конфликтах;
- фильтрация участников по постановкам;
- демонстрационный режим администратора;
- мобильная версия.

## Firebase

Приложение использует Firebase Authentication и Cloud Firestore проекта `abricos`.

Для полной синхронизации необходимо:

1. Включить вход по Email/Password в Firebase Authentication.
2. Создать базу Cloud Firestore.
3. Добавить `noty-chan.github.io` в Authorized domains.
4. Опубликовать правила из `firestore.rules`.
5. После регистрации первого пользователя изменить поле `role` его документа в коллекции `profiles` с `member` на `admin`.

Если Firestore закрыт production-правилами, приложение автоматически использует локальное хранилище: Firebase Authentication продолжает работать, но расписание не синхронизируется между устройствами. Публичная конфигурация веб-приложения находится в `firebase-config.js`. Секретные ключи и Service Account в репозитории не хранятся.

## Готовые рабочие функции

- регистрация, вход и восстановление пароля;
- календарь доступности на 14 дней с быстрым переключением статусов;
- слоты с точным временем и индивидуальными ответами;
- рейтинг пересечений только среди участников нужного спектакля;
- создание и редактирование спектаклей;
- назначение участников в составы;
- отключение доступа к приложению администратором.

Будущий сервер в Нидерландах возьмёт на себя общую синхронизацию и настоящее отключение Firebase Auth-аккаунтов через Firebase Admin SDK. До его подключения административные изменения и расписание сохраняются в браузере каждого устройства.
